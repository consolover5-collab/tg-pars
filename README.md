# tg-pars

Telegram-бот для мониторинга барахолок и групп: ловит объявления по ключевым словам (+ синонимы, стемминг) или фото (Groq Vision), присылает вам уведомление и, если включить, пишет продавцу DM.

> ⚠️ **Начните с режима «только уведомления».** Автоматические DM незнакомым людям — это то, за что Telegram банит аккаунты (жалобы на спам). В `config.example.json` авто-DM выключен (`"auto_dm": false`). Включать его стоит только осознанно и на аккаунте, которого не жалко. Бот работает от **вашего личного аккаунта** Telegram (userbot), а не только от бота.

## Что понадобится

- Linux/macOS (или Docker) и **Python 3.12–3.14** (на 3.15 зависимости пока не ставятся)
- Аккаунт Telegram, под которым бот будет читать чаты (лучше не основной)
- `api_id` и `api_hash`: зайдите на https://my.telegram.org → API development tools → создайте приложение
- Токен бота: напишите @BotFather в Telegram → `/newbot`
- По желанию — бесплатный ключ Groq для распознавания фото (см. ниже)

## Два режима работы

| | 🔤 Базовый (бесплатно) | 🧠 С нейросетями (Groq) |
|---|---|---|
| Ключевые слова + синонимы | ✅ | ✅ |
| Стемминг (колонку = колонка) | ✅ | ✅ |
| Фильтр по цене | ✅ | ✅ |
| Авто-DM по шаблону | ✅ | ✅ |
| Отсев повторов объявлений и скама | ✅ | ✅ |
| 👁 Vision (фото → товар) | ❌ | ✅ |
| 🧬 NLP (семантика текста) | ❌ | ✅ |
| 🤖 Groq DM (генерация текста) | ❌ | ✅ |

Если `vision.api_key` пуст — AI-кнопки скрыты из интерфейса. Бот полностью работает без внешних API.

## Архитектура

| Компонент | Роль |
|-----------|------|
| **Telethon userbot** | Слушает сообщения в заданных группах от вашего аккаунта |
| **aiogram control-bot** | Управление через Telegram: меню, настройки, история |
| **Groq Vision/NLP** | Анализ фото и текста (опционально, бесплатно) |
| **SQLite** | Дедупликация DM, история совпадений, лог действий |

### Pipeline обработки сообщений

```
Сообщение в чате
  → Ранний отсев: чёрный список и скам-рассылки «распродажа списком, фото и цены в личку» — молча
  → Ключевые слова (stem + синонимы)
  → NLP семантика (если включён)
  → Vision анализ фото (если включён + есть фото)
  → Фильтр по цене
  → Повтор? то же объявление от того же продавца за 7 дней — молча (цена ниже → «📉 цена снижена»)
  → Задержка 60–120с (human-like)
  → Авто-DM продавцу
  → Уведомление владельцу + доп. получателям (с фильтром по keywords)
```

## Быстрый старт

### 1. Установка и первый запуск

```bash
git clone https://github.com/consolover5-collab/tg-pars.git
cd tg-pars
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp config.example.json config.json
```

Откройте `config.json` и заполните в блоке `telegram`: `api_id`, `api_hash`, `phone` (номер аккаунта, который будет читать чаты), `bot_token`. В `monitoring.chats` впишите чаты, которые слушать (`@username` публичной барахолки), в `monitoring.keywords` — что искать. Затем:

```bash
python3 main.py
```

Если `config.json` не читается, бот напишет причину в консоль и выйдет. Остановить — `Ctrl+C`.

> ⚠️ Кнопка «Перезапуск» в меню бота завершает процесс и рассчитывает на
> супервизор (systemd/Docker с `Restart=always`). При запуске голым
> `python3 main.py` после перезапуска бот нужно поднять вручную.

### 2. Пользователь (через Telegram)

Откройте в Telegram **своего бота** (того, что создали у @BotFather) и отправьте `/start`. Тот, кто написал первым, становится владельцем: остальным бот не отвечает, так что делайте это сами и сразу. Всё управление — через кнопки:

- 🔐 Авторизация userbot (QR-код или SMS-код)
- 📡 Добавить чаты и ключевые слова
- ✉️ Настроить авто-DM
- Готово — бот мониторит

## config.json — что заполняет установщик

```jsonc
{
  "telegram": {
    "api_id": 123456,          // my.telegram.org
    "api_hash": "abc...",
    "phone": "+7...",          // номер userbot-аккаунта
    "bot_token": "7...:AA..."  // токен от @BotFather
  },
  "vision": {
    "api_key": ""              // пусто = базовый режим, "gsk_..." = AI-режим
  }
}
```

Остальные поля управляются через Telegram-бота. Полный шаблон — `config.example.json`.

## Меню control-бота

### /start — Дашборд
```
📊 Активен | 2 чата | 3 слова
🔍 5 находок | ✉️ 3 DM | 💰 до 30 000₽

[📡 Мониторинг]   [✉️ Авто-DM]
[📋 История]      [⚙️ Настройки]
[⏸ Пауза]        [❓ Помощь]
```

### 📡 Мониторинг
Чаты + ключевые слова с синонимами + макс. цена — всё в одном разделе.
- **Добавить чат**: `@username`, числовой ID, ссылка `t.me/c/ID/...` (приватные каналы), или переслать сообщение из группы
- **Синонимы**: выбрать слово → добавить/удалить синонимы (через запятую)
- **Стемминг**: «колонку» автоматически матчит «колонка», «колонки» и т.д.
- При изменении списка чатов бот перезапускается автоматически

### ✉️ Авто-DM
- Вкл/выкл, шаблон с плейсхолдерами, задержка, повтор
- Плейсхолдеры: `{type}` `{price}` `{link}` `{author}` `{chat_title}` `{message_snippet}`

### ⚙️ Настройки (адаптивное)
- **С Groq API key**: видны кнопки Vision, NLP, Groq DM
- **Без Groq API key**: только dry-run, лимиты, списки
- 🔔 **Уведомления**: добавить получателей по `@username`, каждому — свой набор ключевых слов
- 👥 **Списки**: чёрный (не писать DM) и белый (игнорировать cooldown)
- 📊 **Лимиты**: DM/час, Vision/мин, NLP/мин (действуют сразу, без рестарта)
- 🔄 **Перезапуск**: мягкий рестарт сервиса из меню

## Повторы и скам

- **Повтор** — доставленное владельцу уведомление с тем же текстом (цены не в счёт, остальные цифры в счёт) от того же продавца за `monitoring.dedup_window_days` (по умолчанию 7 дней). Повтор приходит в 2–4 чата сразу — уведомление одно. Цена ниже прежней — уведомление с пометкой «📉 цена снижена: было X». Другой текст или фото без подписи — всегда новое уведомление; `no_dedup_ids` — всегда уведомлять.
- **Скам** — список из 8+ коротких строк без цены в € и со словами «фото/цену — в личку». Сообщения из чёрного списка и скам отсеиваются до ключевых слов и Groq. Аккаунты скамеров в чёрный список автоматически не добавляются.
- Учёт — таблица `notified`; счётчики «отсеяно повторов / скам отсеян» — в ежедневном heartbeat.

## Авторизация userbot

1. `/start` → ⚙️ Настройки → 🔐 Авторизация
2. Отсканируйте QR или перейдите по ссылке на мобильном
3. Если QR не работает — бот переключится на ввод кода из Telegram

> ⚠️ **Если у вас включена 2FA**: временно отключите двухфакторную авторизацию в Telegram, авторизуйте userbot, затем включите 2FA обратно. Сессия сохраняется, повторная авторизация не нужна.

## Синонимы и keyword_map

```json
"keyword_map": {
  "колонка": ["акустика", "speaker", "JBL", "bluetooth", "саундбар"],
  "телевизор": ["телек", "экран", "плазма", "OLED"]
}
```

Синонимы управляются через бота: 📡 Мониторинг → 🏷 Синонимы.
При совпадении синонима в уведомлении показывается основное слово (ключ).

## 🔑 Groq API (опционально, бесплатно)

1. https://console.groq.com → Sign Up → API Keys → Create
2. Скопируйте `gsk_…` в `config.json` → `vision.api_key`

В `config.example.json` стоит модель `qwen/qwen3.8-27b` (понимает и фото, и текст). Лимиты бесплатного тарифа меняются, актуальные смотрите в консоли Groq. На момент написания у этой модели было около 1 000 запросов в сутки и 7 000 входных токенов в минуту. Одно фото тянет ~2 000 токенов, поэтому в конфиге стоит `rate_limits.vision_per_minute: 3`; больше ставить нет смысла.

**Если бот пишет ошибку 403 «blocked at the project level»:** модель надо включить в консоли Groq → Settings → Limits вашего проекта. Пока она не включена, фото и NLP не работают, а остальное продолжает работать.

Vision вызывается **только** когда нет совпадения по тексту, но есть фото. При исчерпании дневного лимита (429 «tokens per day») бот ставит распознавание на паузу ровно на срок из ответа Groq, не тратит на него время и запросы, продолжает работать по ключевым словам, а после паузы сам делает один пробный запрос. В ежедневном heartbeat — «Groq: лимит кончился в HH:MM UTC, распознавание стояло N ч».

## Развёртывание

### systemd (Linux/VPS)

```bash
sudo cp deploy/tg-parsing.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tg-parsing
```

### Docker

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

### Локальные варианты

Бот работает везде — все соединения исходящие, публичный IP не нужен:

| Платформа | Примечания |
|-----------|------------|
| VPS (Ubuntu/Debian) | Рекомендуемый вариант |
| Hyper-V (Ubuntu VM) | Идентично VPS |
| Synology Docker | Container Manager или SSH + docker compose |
| Raspberry Pi | ARM, Python 3.10+ |

**Ограничения:** постоянный интернет. Если MTProto заблокирован — используйте SOCKS5 proxy (Telethon поддерживает через `PySocks`).

## Безопасность

- Сессия Telethon хранится локально в `session/`
- Коды авторизации удаляются из чата сразу после обработки
- 2FA-пароли **не принимаются** через бота — вместо этого инструкция по временному отключению
- `config.json` и `session/` содержат ключи и доступ к вашему аккаунту — не коммитьте их и никому не отдавайте (оба уже в `.gitignore`)

## Если что-то не работает

- Бот молчит на `/start`: его уже занял другой аккаунт (владелец запоминается в базе `data/dedup.db`). Остановите бота, удалите `data/dedup.db` и запустите заново.
- Сообщения из чатов не приходят: userbot не авторизован (⚙️ Настройки → 🔐 Авторизация) или в `monitoring.chats` ошибка в имени чата.
- Подробности — в консоли или в логе сервиса (`journalctl -u tg-parsing -f`).
